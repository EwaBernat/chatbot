# Pliki pomocnicze skilla `cele-fba-pbs`

Przeczytaj ten, który pasuje do prośby — SKILL.md mówi który, w tabeli
*Ścieżki rozbudowy*.

| plik | o czym | kiedy czytać |
|---|---|---|
| `cele.md` | druki FBA-C i FBA-T, struktura danych, skąd kryterium i horyzont | zmiana treści celu, nowy wskaźnik, pytanie o kryteria |
| `konspekt.md` | wzór KC-3, rdzeń i wariant wiekowy, przebieg N/D, arkusz, druk | pisanie albo poprawianie konspektu, brakujący materiał do wycięcia |
| `pomoce.md` | wzór KC-4, zdjęcie, nagranie jej głosem, język poleceń do dziecka | nowa pomoc, nagrania, poprawianie tekstu dla dziecka |
| `edytor.md` | własne konspekty nauczycielki: magazyn, media, pułapki, testowanie | cokolwiek w `moje_konspekty_fba.py` |
