# Zdjęcia do broszur PCTP

Tu wgrywasz zdjęcia, które mają trafić do broszury.

## Jak wgrać

1. Wejdź na ten katalog na GitHubie
2. **Add file → Upload files**
3. Przeciągnij zdjęcia i kliknij **Commit changes**
4. Napisz mi, w które miejsce broszury mają trafić — osadzę je i złożę na nowo

## Jak nazywać pliki

Nazwa mówi, gdzie zdjęcie ma być użyte. Bez polskich znaków i spacji:

```
okladka.jpg
rozdzial-01-czym-jest-echolalia.jpg
rozdzial-06-cwiczenia.jpg
tylna-okladka.jpg
```

## Wymagania techniczne (druk A4)

| Miejsce w broszurze | Minimalna szerokość | Proporcje |
|---|---|---|
| Zdjęcie na całą stronę | 2480 px | 1:1,41 (pion A4) |
| Zdjęcie na pół strony | 1240 px | dowolne |
| Zdjęcie w ramce obok tekstu | 800 px | kwadrat lub 4:3 |

- **Format:** JPG (zdjęcia) lub PNG (grafiki, logo, przezroczystość)
- **Rozdzielczość:** minimum 300 dpi w docelowym rozmiarze druku
- **Waga:** do 5 MB na plik — większe pliki spowalniają repozytorium

## Zanim wgrasz — sprawdź prawa

Do broszury płatnej wolno użyć wyłącznie zdjęć, do których masz prawa:

- własne fotografie,
- zdjęcia z licencją komercyjną (np. wykupione ze stocka),
- zdjęcia osób, od których masz **pisemną zgodę na wykorzystanie wizerunku** —
  w przypadku dzieci zgodę podpisuje rodzic lub opiekun prawny.

Zdjęcia znalezione w wyszukiwarce lub pobrane z serwisów bez licencji
komercyjnej nie mogą trafić do publikacji płatnej.

## Alternatywa

Broszura jest obecnie w całości wektorowa — ilustracje są rysowane kodem,
więc drukują się ostro w każdym formacie i nie wymagają licencji.
Zdjęcia można dodać punktowo, tam gdzie naprawdę coś wnoszą.
